### 🛡️ 2. Feature — ระบบจำกัดการทำข้อสอบ (Max 2 Attempts) & Anti-Cheat Auto-Submit

**ความต้องการ:**

- นักเรียนมีโอกาสทำข้อสอบได้สูงสุด **2 ครั้ง** เท่านั้น
- มีระบบตรวจจับการโกง (Fullscreen exit / Tab blur) หากตรวจจับครบจำนวนที่กำหนด ระบบจะทำการ **ส่งข้อสอบทันทีโดยอัตโนมัติ** และคำนวณคะแนนตามข้อที่ตอบไว้

**การเปลี่ยนแปลง:**

#### Backend

- **Prisma Schema / Database:**
  - รองรับการนับ `attemptNumber` (1 หรือ 2) และ flag `submittedByCheat`
- **`test.service.ts` & `test.controller.ts`:**
  - เพิ่ม logic ตรวจสอบสิทธิ์การเริ่มทำข้อสอบ (เช็คว่า attempt เกิน 2 หรือไม่)
  - เพิ่ม API endpoint สำหรับเริ่ม attempt (`POST /test/:id/attempt/start`)
  - เพิ่ม logic ตรวจรับ flag `submittedByCheat` ตอนส่งข้อสอบ (`POST /test/:id/attempt/:attemptId/submit`) พร้อมคำนวณคะแนนทันที

#### Frontend

- **`src/app/(main)/course/[id]/test/[testId]/page.tsx`:**
  - ระบบ Fullscreen Guard & Anti-cheat event listener (ตรวจจับ `visibilitychange`, `blur`, `fullscreenchange`)
  - Warning counter แสดงเตือนเมื่อหลุดออกจากหน้าจอสอบ
  - เมื่อ cheat warning ถึงขีดจำกัด ทำการ trigger `handleSubmitExam(true)` ทันที
  - แสดงสถานะจำนวนครั้งที่ทำไปแล้ว (Attempt 1 / 2)

### 📊 3. Feature — Dashboard คะแนนข้อสอบสำหรับครู/ผู้สอน (Teacher Test Score Dashboard)

สร้างหน้าและ API สำหรับแสดงภาพรวมคะแนนของนักเรียนทุกคนในแต่ละ Test ของ Course

#### Backend

| Layer         | ไฟล์                                                | หน้าที่                                                                                                                                                              |
| ------------- | --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Service       | `apps/edu-flow-api/src/pkg/test/test.service.ts`    | เพิ่ม `getScoreDashboard(testId)` — ดึงรายชื่อนักเรียนที่ enroll ใน course ทั้งหมด พร้อม match ข้อมูล attempt 1, 2, best score, percentage, วันที่ส่ง และสถานะการโกง |
| Controller    | `apps/edu-flow-api/src/pkg/test/test.controller.ts` | เพิ่ม `getScoreDashboard` method (`GET /test/:id/dashboard`)                                                                                                         |
| Module Router | `apps/edu-flow-api/src/pkg/test/test.module.ts`     | ลงทะเบียน route `GET /test/:id/dashboard` (วางก่อน `/:id` เพื่อป้องกัน route collision)                                                                              |

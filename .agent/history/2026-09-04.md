### 🛡️ 2. Feature — ระบบจำกัดการทำข้อสอบ (Max 2 Attempts) & Anti-Cheat Auto-Submit

**ความต้องการ:**
- นักเรียนมีโอกาสทำข้อสอบได้สูงสุด **2 ครั้ง** เท่านั้น
- มีระบบตรวจจับการโกง (Fullscreen exit / Tab blur) หากตรวจจับครบจำนวนที่กำหนด ระบบจะทำการ **ส่งข้อสอบทันทีโดยอัตโนมัติ** และคำนวณคะแนนตามข้อที่ตอบไว้

**การเปลี่ยนแปลง:**

#### Backend
- **Prisma Schema / Database:**
  - รองรับการนับ `attemptNumber` (1 หรือ 2) และ flag `submittedByCheat`
- **`test.service.ts` & `test.controller.ts`:**
  - เพิ่ม logic ตรวจสอบสิทธิ์การเริ่มทำข้อสอบ (เช็คว่า attempt เกิน 2 หรือไม่)
  - เพิ่ม API endpoint สำหรับเริ่ม attempt (`POST /test/:id/attempt/start`)
  - เพิ่ม logic ตรวจรับ flag `submittedByCheat` ตอนส่งข้อสอบ (`POST /test/attempt/:attemptId/submit`) พร้อมคำนวณคะแนนทันที

#### Frontend
- **`src/app/(main)/course/[id]/test/[testId]/page.tsx`:**
  - ระบบ Fullscreen Guard & Anti-cheat event listener (ตรวจจับ `visibilitychange`, `blur`, `fullscreenchange`)
  - Warning counter แสดงเตือนเมื่อหลุดออกจากหน้าจอสอบ
  - เมื่อ cheat warning ถึงขีดจำกัด ทำการ trigger auto-submit ทันที
  - แสดงสถานะจำนวนครั้งที่ทำไปแล้ว (Attempt 1 / 2)

### 🗑️ 4. Bug Fix — แก้ไขระบบการลบข้อสอบ (Delete Test Cascade Transaction)

**ปัญหา:**
- เมื่อมีนักเรียนทำข้อสอบไปแล้ว การลบ Test จากฐานข้อมูลติดข้อผิดพลาด Foreign Key Constraint (`P2003`) เนื่องจากตาราง `Attempt` และ `StudentAnswer` ไม่มี cascade ในฐานข้อมูล

**การแก้ไข:**
- ปรับปรุง `test.service.ts` ในฟังก์ชัน `delete(testId: string)` ให้ทำงานผ่าน `prisma.$transaction`:
  1. ดึง `attemptIds` ทั้งหมดของ test นั้น
  2. ลบ `StudentAnswer` ของ attempts ทั้งหมด
  3. ลบ `Attempt` ทั้งหมดของ test นั้น
  4. ลบ `Choice` และ `Question` ทั้งหมดของ test นั้น
  5. ลบ `Test` ออกจากฐานข้อมูลอย่างปลอดภัย

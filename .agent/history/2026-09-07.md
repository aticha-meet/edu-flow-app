### ⚙️ 1. Feature — Course Settings Page & Delete Course

สร้างหน้า Settings ภายใน Course (ผ่าน Sidebar menu) แทนการใช้ popup สำหรับการลบ และรองรับการปรับแต่ง config ของ course

#### Backend

| Layer         | ไฟล์                                                    | หน้าที่                                                                                                                            |
| ------------- | ------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Service       | `apps/edu-flow-api/src/pkg/course/course.service.ts`    | เพิ่ม `updateCourse()`, `deleteCourse()`, `findCourseOwner()`                                                                      |
| Controller    | `apps/edu-flow-api/src/pkg/course/course.controller.ts` | เพิ่ม handler `updateCourse` + `deleteCourse` พร้อม role-based access control (ADMIN ทำได้ทุก course, TEACHER เฉพาะ course ตัวเอง) |
| Module Router | `apps/edu-flow-api/src/pkg/course/course.module.ts`     | ลงทะเบียน `PATCH /course/:id` และ `DELETE /course/:id`                                                                             |

**Security Logic:**

- ADMIN → ลบ/แก้ไขได้ทุก course
- TEACHER → ลบ/แก้ไขได้เฉพาะ course ที่ตัวเองสร้าง (ตรวจผ่าน `findCourseOwner`)
- Prisma Schema มี `onDelete: Cascade` ครบบน `Enrollment`, `Test`, `CourseSyllabus` → ลบ course แล้วลบ data ย่อยทั้งหมดทันที

#### Frontend

| ไฟล์                                                  | การเปลี่ยนแปลง                                                                                                                                                                                                                              |
| ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/api/course/controller.ts`                        | เพิ่ม `updateCourse(courseId, data)` และ `deleteCourse(courseId, meta)`                                                                                                                                                                     |
| `src/components/course/CourseSidebar.tsx`             | เพิ่ม `'settings'` ใน `MenuKey` union type + เมนู ⚙️ **Course Settings** พร้อม gear icon (ซ่อนจาก STUDENT)                                                                                                                                  |
| `src/components/course/CourseSettings.tsx`            | **[ใหม่]** หน้า Settings มี 2 section: **Config Form** (แก้ไข className, description, code, roomId, maxStudents, status) และ **Danger Zone** (accordion collapsible สำหรับลบ course)                                                        |
| `src/components/course/course-components.module.scss` | เพิ่ม styles ครอบคลุม settings page, form grid, alert banners, spinner, danger zone accordion, confirm input, delete button                                                                                                                 |
| `src/app/(main)/course/[id]/page.tsx`                 | Wired up settings panel — import `CourseSettings`, เพิ่ม `userId` extraction จาก session, เพิ่ม `handleCourseUpdated` callback, render `<CourseSettings>` เมื่อ `activeMenu === 'settings'`, ปรับ breadcrumb และ title row ตาม active panel |

**Danger Zone UX:**

- ต้องพิมพ์ **ชื่อ course** ให้ตรงกันเป๊ะ → ปุ่มลบจึง enable
- ไม่มี popup — ทุกอย่างอยู่ใน inline panel ใต้ accordion
- หลังลบสำเร็จ → redirect กลับ `/course` ทันที

### 📥 3. Feature — CSV Import Student

รองรับการ Import นักเรียนจากไฟล์ CSV แบบ bulk พร้อม drag-and-drop UI และ example file ให้ดาวน์โหลด

#### CSV Format

```
studentId,firstName,lastName,email,section,room
6401001,สมชาย,ใจดี,somchai@example.com,ปวส.1,2
6401002,สมหญิง,รักเรียน,somying@example.com,ปวช.2,1
```

**Import Logic:**

- Email ซ้ำ → **skip** (ไม่ error)
- studentId ซ้ำ → **skip**
- ข้อมูลไม่ครบ (ไม่มี studentId / email / firstName) → **error row**
- รายงาน summary: `{imported, skipped, errors[]}`

#### Frontend

| ไฟล์                                                       | การเปลี่ยนแปลง                                                                                                                                                                                    |
| ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/api/user/controller.ts`                               | เพิ่ม `importStudentsCSV(csvText)` และ `getStudentCSVExampleUrl()`                                                                                                                                |
| `src/components/course/ImportCSVModal.tsx`                 | **[ใหม่]** Modal 3 steps: **Upload** (drag-drop + format hint + download example), **Importing** (loading spinner), **Result** (3 stat cards: imported/skipped/errors + error table)              |
| `src/components/course/import-csv-modal.module.scss`       | **[ใหม่]** Full styling — overlay, drag-drop zone animate, file preview, result cards, error table                                                                                                |
| `src/app/(main)/course/[id]/students/page.tsx`             | **Rewrite** — เพิ่ม `ImportCSVModal`, ปุ่ม **"Import CSV"** ใน header, `classroomBadge` แสดง section+room บน student card, section filter dropdown, แสดง classroom info ใน dropdown เพิ่มนักเรียน |
| `src/app/(main)/course/[id]/students/students.module.scss` | เพิ่ม `.pageHeader`, `.headerActions`, `.importCsvBtn`, `.classroomBadge`, `.filterSelect`                                                                                                        |

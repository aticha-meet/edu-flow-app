### 1.1 เพิ่ม `getTeachers()` ใน User API Controller

```ts
// src/api/user/controller.ts
export const getTeachers = async () => {
    try {
        const request = await axiosInstance.get(`${PAGE_PATH.API_URL}/teachers`)
        return request.data
    } catch (err) {
        console.log(err);
        throw err;
    }
}
```

- เรียก `GET /teachers` ซึ่งมีอยู่แล้วใน backend (`TeacherRouter.get("/teachers", getTeacherProfiles)`)
- Backend return `{ message, data: teacherProfile[] }` โดยแต่ละ entry include `user` relation

### 1.2 แก้ `CreateClassPopup.tsx`

**เพิ่ม State:**
```ts
const [teachers, setTeachers] = useState<TeacherOption[]>([]);
const [isLoadingTeachers, setIsLoadingTeachers] = useState(false);
```

**เพิ่ม Type:**
```ts
interface TeacherOption {
    id: string;
    userId: string;
    department: string;
    user: {
        id: string;
        name: string;
        email: string;
    };
}
```

**Fetch teachers ตอน popup เปิด (useEffect):**
```ts
useEffect(() => {
    const fetchTeachers = async () => {
        setIsLoadingTeachers(true);
        try {
            const res = await getTeachers();
            setTeachers(res.data || []);
        } catch (err) {
            setTeachers([]);
        } finally {
            setIsLoadingTeachers(false);
        }
    };
    fetchTeachers();
}, []);
```

**เปลี่ยน Input → Select:**
```tsx
// ❌ ก่อน
<input
    type="text"
    id="teacherId"
    name="teacherId"
    placeholder="UUID ของอาจารย์ผู้สอน"
    ...
/>

// ✅ หลัง
<select
    id="teacherId"
    name="teacherId"
    className={styles?.formSelect}
    value={formData.teacherId}
    onChange={handleSelectChange}
    disabled={isLoadingTeachers}
>
    <option value="">
        {isLoadingTeachers ? 'กำลังโหลด...' : '-- เลือกอาจารย์ผู้สอน --'}
    </option>
    {teachers.map((teacher) => (
        <option key={teacher.userId} value={teacher.userId}>
            {teacher.user?.name || teacher.user?.email}
            {teacher.department ? ` (${teacher.department})` : ''}
        </option>
    ))}
</select>
```

> **หมายเหตุ:** `value` ที่ส่งไปคือ `teacher.userId` (User.id) ไม่ใช่ TeacherProfile.id เพราะ Prisma schema กำหนดว่า `Class.teacherId` อ้างอิงถึง `User.id`

**เพิ่ม handleSelectChange:**
```ts
const handleSelectChange = (e: React.ChangeEvent<HTMLSelectElement>) => {
    const { name, value } = e.target;
    setFormData((prev: formDataType) => ({ ...prev, [name]: value }));
    setFormError('');
};
```

### 1.3 เพิ่ม `.formSelect` ใน SCSS

- ดีไซน์ match กับ `.formInput` / `.formTextarea` (dark theme, border-radius 12px)
- ใช้ `appearance: none` + SVG background-image เป็น custom dropdown arrow
- Arrow เปลี่ยนสีจาก slate (`#64748b`) → indigo (`#6366f1`) ตอน focus
- มี `:disabled` state สำหรับตอน loading

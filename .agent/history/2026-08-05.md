# 📋 EduFlow — Development History

---

## 2026-08-05 — ระบบข้อสอบ (Test & Exam System)

### 🔧 Backend — `edu-flow-api`

#### ไฟล์ใหม่: `src/pkg/test/`

| ไฟล์                 | รายละเอียด                                                                                          |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| `test.service.ts`    | Prisma service สำหรับ `Test`, `Question`, `Choice` — `findByCourse`, `findById`, `create`, `delete` |
| `test.controller.ts` | Express controller — validate input และจัดการ error                                                 |
| `test.module.ts`     | Express Router ลงทะเบียน 4 endpoints                                                                |

#### API Endpoints ใหม่

| Method   | Path                 | หน้าที่                                             |
| -------- | -------------------- | --------------------------------------------------- |
| `GET`    | `/test?courseId=...` | ดึงรายการ Test ทั้งหมดของ course                    |
| `GET`    | `/test/:id`          | ดึง Test พร้อม Questions + Choices (ใช้หน้าสอบ)     |
| `POST`   | `/test`              | สร้าง Test พร้อม Questions และ Choices ในครั้งเดียว |
| `DELETE` | `/test/:id`          | ลบ Test (cascade ลบ Questions + Choices)            |

#### ไฟล์แก้ไข

- `src/router.ts` — เพิ่ม `TestRouter`

---

### 🎨 Frontend — `edu-flow-front`

#### Types ใหม่: `src/types/TestType.ts`

- `TestSummary` — ข้อมูลย่อสำหรับแสดงรายการ
- `TestWithQuestions` — ข้อมูลเต็มพร้อม Questions + Choices
- `QuestionWithChoices`, `Choice`
- `CreateTestPayload` — payload สำหรับ POST /test

#### API Layer ใหม่: `src/api/test/controller.ts`

- `getTestsByCourse(courseId)` — ดึงรายการ Test
- `getTestById(testId)` — ดึง Test สำหรับหน้าสอบ
- `createTest(payload)` — สร้าง Test
- `deleteTest(testId)` — ลบ Test

### 🧩 Component: `CreateTestModal` (เขียนใหม่)

**ก่อน:** รับแค่ชื่อ + วันที่
**หลัง:** ฟอร์มสร้างข้อสอบแบบ dynamic

| ฟีเจอร์               | รายละเอียด                                        |
| --------------------- | ------------------------------------------------- |
| เพิ่ม/ลบข้อสอบ        | dynamic ไม่จำกัดจำนวนข้อ                          |
| เพิ่ม/ลบตัวเลือก      | แต่ละข้อมีตัวเลือกได้หลายตัว (ขั้นต่ำ 2)          |
| ระบุเฉลย              | คลิก ● toggle คำตอบที่ถูกต้อง                     |
| Validation            | ตรวจสอบทุกข้อก่อน submit                          |
| **Import JSON**       | ปุ่ม upload ไฟล์ `.json` เพื่อนำเข้าข้อสอบทั้งชุด |
| **Download Template** | ดาวน์โหลด `exam-template.json` เป็นตัวอย่าง       |
| Success/Error message | แจ้งผลการ import พร้อมชื่อ test และจำนวนข้อ       |

**รูปแบบ JSON ที่รองรับ:**

```json
{
  "title": "ชื่อแบบทดสอบ",
  "questions": [
    {
      "questionText": "คำถาม...",
      "choices": [
        { "value": "ตัวเลือก ก", "isCorrect": false },
        { "value": "ตัวเลือก ข", "isCorrect": true }
      ]
    }
  ]
}
```

### 🏃 หน้า `/test/[id]` (ใหม่ — หน้าสอบจริง)

Route เก่า `/exam` ใช้ข้อมูล mock เท่านั้น
Route ใหม่ `/test/[id]` โหลดจาก DB จริงทุก test

| ฟีเจอร์          | รายละเอียด                                                              |
| ---------------- | ----------------------------------------------------------------------- |
| โหลดข้อสอบจาก DB | `getTestById(id)` — Questions + Choices จริง                            |
| นับเวลา          | 90 วินาที/ข้อ — auto-submit เมื่อหมดเวลา                                |
| Navigator        | คลิก dot ข้ามข้อได้                                                     |
| Progress bar     | แสดง % ที่ตอบแล้ว                                                       |
| **Anti-Cheat**   | ตรวจจับสลับ tab / ออก fullscreen → เตือน → auto-submit เมื่อครบ 5 ครั้ง |
| **PDF Export**   | jsPDF + font Sarabun (ภาษาไทย) — ชื่อ test, คะแนน, ทุกข้อพร้อมเฉลย      |
| หน้าผลลัพธ์      | ScoreRing, ไอคอนเกรด, ถูก/ผิด/รวม                                       |
| หน้าดูเฉลย       | navigator เขียว/แดง, แสดงคำตอบที่เลือกและเฉลย                           |
| ทำใหม่           | reset state ทั้งหมด                                                     |

> ใช้ `exam.module.scss` ร่วมกับหน้า `/exam` — ไม่ duplicate CSS

### 🔐 Feature — Role-Based Navbar Profile Creation

**ไฟล์แก้ไข:**
- `apps/edu-flow-front/src/components/navbar.tsx`
- `apps/edu-flow-front/src/components/profile/CreateProfilePopup.tsx`

**พฤติกรรมใหม่:**

| Role    | สร้างโปรไฟล์ได้              |
| ------- | ---------------------------- |
| `ADMIN` | ครู และ นักเรียน (เหมือนเดิม) |
| `TEACHER` | เฉพาะ **นักเรียน** เท่านั้น  |

**การแก้ไข:**
- `Navbar` ดึง session จาก `useSession()` → คำนวณ `allowedRoles`
- `CreateProfilePopup` รับ prop `allowedRoles?: ProfileRole[]` ใหม่
  - ซ่อน tab ที่ไม่ได้รับอนุญาต
  - `defaultRole` ถูก set เป็น `'student'` อัตโนมัติเมื่อ `allowedRoles = ['student']`

### ⏱ Feature — กำหนดเวลาทำแบบทดสอบได้ (durationMinutes)

**ก่อน:** เวลาสอบถูก hardcoded เป็น `questions.length × 90 วินาที`
**หลัง:** ครู/Admin กำหนดเวลาได้ตอนสร้างข้อสอบ (1–300 นาที, default 45 นาที)

#### Database

**ไฟล์:** `prisma/schema.prisma`

```prisma
model Test {
  // ...
  durationMinutes Int @default(45) // ✅ ใหม่
  // ...
}
```

> ⚠️ ต้องรัน: `pnpm prisma migrate dev --name add_duration_minutes_to_test`

#### Backend

| ไฟล์                  | การเปลี่ยนแปลง                                         |
| --------------------- | ------------------------------------------------------ |
| `test.service.ts`     | `create()` รับและบันทึก `durationMinutes`              |
| `test.controller.ts`  | รับ `durationMinutes` จาก body + validate (1–300)      |

#### Frontend

| ไฟล์                          | การเปลี่ยนแปลง                                              |
| ----------------------------- | ----------------------------------------------------------- |
| `src/types/test-type.ts`      | เพิ่ม `durationMinutes` ใน `TestSummary`, `TestWithQuestions`, `CreateTestPayload` |
| `CreateTestModal.tsx`         | เพิ่ม **input ตั้งเวลา** พร้อม hint แสดง ชม./นาที           |
| `test/manage/page.tsx`        | ส่ง `durationMinutes` ใน `handleCreate`                     |
| `TestList.tsx`                | แสดง ⏱ XX นาที ในการ์ดแต่ละข้อสอบ                          |
| `test/[id]/page.tsx`          | timer ใช้ `durationMinutes * 60` วินาที                     |

### 🔒 Security Note

ทดสอบ SQL Injection ผ่าน JSON import ข้อสอบ — **ปลอดภัย** เพราะ Prisma ใช้ parameterized queries ทั้งหมด จุดที่ควรระวังคือ XSS เมื่อ render `value`/`questionText` — ปัจจุบัน React escape HTML โดยอัตโนมัติผ่าน `{text}` syntax

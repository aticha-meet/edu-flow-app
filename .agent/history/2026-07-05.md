## 2. 🔧 แก้ `CLIENT_FETCH_ERROR` จาก Next-Auth

**ปัญหา:** `[next-auth][error][CLIENT_FETCH_ERROR] "Unexpected token '<', "<!DOCTYPE "... is not valid JSON"`

**สาเหตุ:** Middleware ไป block `/api/auth/session` ของ next-auth เพราะไม่มี `ac_tk` cookie → redirect เป็น HTML ไปให้ next-auth แทน JSON ทำให้ parse ไม่ได้

**วิธีแก้:** เพิ่ม `/api/auth` เข้า `PUBLIC_PATHS` เพื่อให้ next-auth internal routes ผ่านได้เสมอ

## 3. 🔑 ดึง `refreshToken` จาก Next-Auth JWT ใน Middleware

**เป้าหมาย:** เข้าถึง `refreshToken` ที่เก็บไว้ใน JWT cookie ของ next-auth โดยตรงจาก middleware โดยไม่ต้องเรียก API

**วิธีการ:**
```ts
import { getToken } from 'next-auth/jwt';

const jwtToken = await getToken({
    req: request,
    secret: process.env.NEXTAUTH_SECRET, // ต้องใช้ NEXTAUTH_SECRET เท่านั้น
});
const refreshToken = jwtToken?.refreshToken as string | undefined;
```

**Flow ที่ next-auth เก็บ refreshToken:**
```
Google OAuth → account.refresh_token
             ↓ jwt() callback ใน OauthConfig.ts (บรรทัด 35)
       token.refreshToken = account.refresh_token
             ↓ encrypt ลงใน JWT cookie
       cookie: "next-auth.session-token"
             ↓ getToken() ใน middleware decode ออกมา
       jwtToken.refreshToken ✅
```

**หมายเหตุเพิ่มเติม:** ต้อง extend `JWT` interface ใน `src/types/next-auth.d.ts` ด้วย:
```ts
declare module "next-auth/jwt" {
    interface JWT {
        refreshToken?: string;
        expiresAt?: number;
    }
}
```
เพื่อให้ TypeScript รู้จัก field `refreshToken` ใน JWT payload

## 4. 🐛 แก้ Bug `TypeError: Cannot read properties of null (reading 'refreshToken')`

**สาเหตุ:** 2 ปัญหาในบรรทัดเดียวกัน
1. ใช้ `secret: process.env.NEXT_PUBLIC_API_JWT_SECRET` ผิด env var → `getToken()` ถอดรหัสไม่ได้ → return `null`
2. Cast เป็น `{ refreshToken: string }` ทั้งที่ยังไม่ตรวจว่าเป็น null → `null.refreshToken` → crash

**วิธีแก้:**
```ts
// ❌ ก่อน
const session = await getToken({ secret: process.env.NEXT_PUBLIC_API_JWT_SECRET }) as { refreshToken: string }
console.log(session.refreshToken) // crash ถ้า null

// ✅ หลัง
const session = await getToken({ secret: process.env.NEXTAUTH_SECRET });
const refreshToken = session?.refreshToken as string | undefined; // null-safe
```

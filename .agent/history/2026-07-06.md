### Controller (`createClass`)

**สิ่งที่ทำ:**
- Implement ฟังก์ชัน `createClass` ที่เดิมเป็น stub ว่างเปล่า (มีแค่ `console.log(req)`)
- รับ `className`, `description`, `teacherId`, `role` จาก `req.body`

**Logic ที่เพิ่ม:**

| ขั้นตอน | รายละเอียด | HTTP Status |
|---|---|---|
| **ตรวจสิทธิ์** | `role !== 'ADMIN'` → ปฏิเสธ | `403 Forbidden` |
| **Validate fields** | ขาด `className` หรือ `teacherId` | `400 Bad Request` |
| **ตรวจ Teacher** | หา user จาก `teacherId` ถ้าไม่พบ | `404 Not Found` |
| **ตรวจ Role ครู** | user ต้องเป็น TEACHER หรือ ADMIN | `400 Bad Request` |
| **สร้าง Class** | `prisma.class.create()` พร้อม include teacher info | `201 Created` |

```ts
// ตัวอย่าง request body
{
    "className": "Introduction to Computer Science",
    "description": "วิชาพื้นฐานวิทยาการคอมพิวเตอร์",
    "teacherId": "uuid-of-teacher",
    "role": "ADMIN"
}
```

### Route

**สิ่งที่เพิ่ม:**
- `ClassRouter.post("/class", createClass);` — เพิ่ม POST route
- import `createClass` จาก controller

## 2. 🌐 Frontend API Layer — เพิ่มฟังก์ชัน `createClass`

**ไฟล์ที่แก้ไข:**
- [`controller.ts`](file:///D:/project/edu-flow-app/apps/edu-flow-front/src/api/class/controller.ts)

**สิ่งที่เพิ่ม:**
```ts
export const createClass = async (data: {
    className: string;
    description?: string;
    teacherId: string;
    role: string;
}) => {
    const request = await axiosInstance.post(`${PAGE_PATH.API_URL}/class`, data);
    return request.data;
}
```

- ใช้ `axiosInstance` ที่มี interceptor แนบ Authorization header อัตโนมัติ
- ส่ง POST request ไปที่ `/class` พร้อม body ทั้งหมด

### การตรวจสอบสิทธิ์ (Role Check)

```ts
const sessionFromStore = useUserStore((state: any) => state.session);
const isAdmin = sessionFromStore?.role === 'ADMIN';
```

- ดึง `role` จาก `useUserStore` → ถ้าเป็น `ADMIN` จะแสดงปุ่ม "เพิ่มรายวิชา"
- ถ้าไม่ใช่ ADMIN ปุ่มจะไม่แสดงเลย (ไม่ใช่แค่ disabled)

### Modal Popup

**State ที่เพิ่ม:**
- `isModalOpen` — เปิด/ปิด modal
- `isSubmitting` — loading state ขณะ submit
- `formData` — `{ className, description, teacherId }`
- `formError` / `formSuccess` — ข้อความ error/success

**Features:**
| Feature | รายละเอียด |
|---|---|
| **Glassmorphism Overlay** | `backdrop-filter: blur(8px)` พร้อม fade-in animation |
| **Slide-up Animation** | modal ขึ้นมาด้วย `translateY(24px) → 0` + `scale(0.96 → 1)` |
| **Form Validation** | ตรวจ className และ teacherId ว่าไม่ว่าง |
| **Error Message** | แสดง error จาก API หรือ validation (สีแดง) |
| **Success Message** | แสดง "สร้างรายวิชาสำเร็จ!" (สีเขียว) แล้ว auto-close |
| **Loading Spinner** | spinner animation ขณะ submit |
| **Click-outside-to-close** | คลิก overlay ปิด modal (ยกเว้นขณะ submit) |
| **ESC-safe** | ป้องกันปิดขณะกำลัง submit |
| **Responsive** | ปุ่มเรียงแนวตั้งบนมือถือ |

### SCSS ที่เพิ่ม (Modal Styles)

เพิ่ม styles ใหม่ ~260 บรรทัด ใน `class.module.scss`:
- `.modalOverlay` — fixed overlay + blur
- `.modalContent` — dark glassmorphism panel
- `.modalClose` — ปุ่มกากบาท มี hover effect สีแดง
- `.modalHeader` — icon + title + subtitle
- `.modalForm` — form layout
- `.formInput` / `.formTextarea` — input fields พร้อม focus glow effect (indigo)
- `.formMessage` — error (แดง) / success (เขียว)
- `.cancelBtn` / `.submitBtn` — ปุ่มด้านล่าง
- `.spinner` — loading animation
- Responsive breakpoint (768px) — modal padding ลด, ปุ่มเรียงแนวตั้ง
